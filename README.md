## 🎯 Sobre o Repositório

O objetivo deste repositório é registrar minha evolução técnica no desenvolvimento web frontend e servir como portfólio prático. 

Os exercícios cobrem conceitos cruciais como:
- **HTML5:** Semântica e acessibilidade (a11y)
- **CSS3:** Flexbox, CSS Grid, responsividade, animações e pré-processadores
- **JavaScript (ES6+):** Lógica, manipulação da DOM, assincronismo (`async/await`, `fetch`) e eventos
- **Frameworks & Libs:** Componentização, gerenciamento de estado e roteamento

---

## 🛠️ Tecnologias Utilizadas

- **Linguagens:** HTML5, CSS3, JavaScript, TypeScript
- **Frameworks & Libs:** React, Tailwind CSS, Styled Components
- **Ferramentas:** Git, VS Code, Vite, Live Server
- **Deploy:** GitHub Pages / Vercel / Netlify
